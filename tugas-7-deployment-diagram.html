BAB I: PENDAHULUAN & LANDASAN TEORI

Sistem Informasi Pengajuan Surat Siswa Berbasis Web (SIPESAT) adalah platform layanan digital mandiri yang dirancang untuk mengotomatisasi birokrasi persuratan siswa di sekolah menengah (Surat Keterangan Siswa Aktif, Rekomendasi Beasiswa, Legalisir Ijazah, dan Dispensasi). Sistem ini mengadopsi arsitektur terpisah (Decoupled Architecture) antara antarmuka web (Frontend), layanan logika bisnis (Backend REST API), dan penyimpanan data terisolasi (PostgreSQL Database).

Untuk memastikan sistem dapat dioperasikan secara stabil, aman, dan berkesinambungan di lingkungan produksi nyata, diperlukan pemodelan arsitektur infrastruktur fisik dan virtual melalui Deployment Diagram.

Konsep Dasar Deployment Diagram (UML 2.5)

Deployment Diagram memetakan bagaimana artefak-artefak perangkat lunak (software artifacts) didistribusikan dan dieksekusi di atas simpul-simpul komputasi fisik maupun lingkungan eksekusi virtual (hardware nodes and execution environments):

  • Node («device»): Representasi perangkat komputasi fisik (PC Klien, Server Fisik, atau Virtual Machine).
  • Execution Environment («executionEnvironment»): Lingkungan eksekusi perangkat lunak (Node.js Runtime, Browser Engine, Docker Engine).
  • Artifact («artifact»): Berkas fisik konkret hasil kompilasi program (.next build, dist JS, database schema).
  • Component («component»): Unit modular logika fungsional dalam runtime (AuthMiddleware, Controllers, Prisma Client).
  • Communication Path («protocol»): Jalur komunikasi jaringan antar simpul (HTTP/HTTPS, REST API JSON, TCP/IP Port 5432).

BAB III: SPESIFIKASI NODE DAN ARTEFAK SISTEM

Simpul / Node Lingkungan Eksekusi Peran & Tanggung Jawab Komputasi
Client Device («device») Web Browser (Chrome, Edge, Safari) Menjalankan antarmuka pengguna grafis, validasi input formulir sisi klien, dan penyimpanan token sesi JWT.
Web Server Host («device») Next.js 14 Web Server (Port 3000) Menyajikan bundel halaman web, Server-Side Rendering (SSR), optimasi gambar, dan routing aplikasi.
API Server Host («device») Express.js + TypeScript (Port 5000) Mengeksekusi logika bisnis, otorisasi RBAC (JWT), penomoran surat otomatis, pembuatan PDF ber-QR Code, dan upload berkas.
Database Server («container») PostgreSQL 16 Alpine (Port 5432) Mengelola basis data relasional 3NF sipesat_db, integritas Foreign Key, dan transaksi ACID.

BAB IV: KESIMPULAN

Pemodelan Deployment Diagram pada sistem SIPESAT mendokumentasikan pemisahan tanggung jawab antarlapisan secara presisi. Melalui pendekatan Decoupled 3-Tier Architecture yang didukung isolasi container Docker, sistem SIPESAT menjamin skalabilitas independen antara frontend dan backend, keandalan dan integritas penyimpanan basis data, serta kemudahan proses deployment baik secara lokal maupun ke cloud VPS.
